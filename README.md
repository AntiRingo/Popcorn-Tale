# 爆米花物语 · Popcorn Tales

一款纯 HTML5 Canvas 像素风回合制挂机游戏。花花从一颗原味爆米花出发，击败美食与调料魔物，寻找属于自己的味道。

## 开始游戏

- 双击 `dist/index.html` 即可游玩，无需联网或安装依赖。
- 开发模式：安装 Node.js 后运行 `npm run dev`，访问 http://localhost:5173。
- `npm run build` 生成可独立分发的单文件网页 `dist/index.html`。
- `npm test` 运行战斗、离线进度、经济系统与存档测试。

## 玩法

战斗、出怪、拾取战利品与升级全部自动进行。持续击败一个区域的普通魔物后，有概率发现该区域的隐藏 Boss 房；探索进度在后台保存，界面不显示发现所需的击杀计数。发现的入口会永久保留，必须通过冒险页面或地图手动进入，离线结算不会自动挑战首领。打败首领解锁下一站；开启自动前往时，达到该区建议等级后会自动旅行。也可以通过地图返回已解锁的区域。

装备包含武器、防具、护符和戒指四个栏位，具有普通、精良、稀有、史诗、传说五种品质。获得装备时，按攻击、防御、生命及特殊属性的综合评分自动替换对应栏位，同分保留当前装备。未穿戴装备按自动分解规则处理，其余进入仓库；同属性装备堆叠，可按类型筛选和翻页。强化绑定当前职业的栏位，更换装备仍保留强化。每个职业独立保存等级、经验、生命、穿戴装备、栏位强化和天赋，切换后恢复该职业的成长；新职业从 Lv.1 开始。金币、素材、调料、风味、图纸、地图与仓库共享。任一职业达到解锁等级后，切换到低级职业仍可选择已解锁职业。转职会退出战斗、保留 Boss 入口并重新探索，必要时返回适合该职业等级的区域；死亡和现实事务的期限不变。

装备工坊增加「装备强化」面板。强化同时消耗金币和餐具矿石、玉米纤维；首次强化需要 200 金币、10 份主要素材和 6 份次要素材，费用随强化等级递增。从 +5 强化至 +6 起额外消耗风味精华。角色升级经验调整为 `90 + 60 × 等级 + 12 × 等级²`，升级所需经验较上一版增加 50%；强化金币按 1.7 倍递增，图纸制作的金币、调料和素材费用一并提高，风味研发从 15 份调料起，每级增加 15 份。已有等级、强化和经验数值保留。

共享仓库支持手动装备、单件分解、整组分解和装备锁定。装备面板可将穿戴物品放回共享仓库，再切换职业取用；每件装备同时只能由一个职业穿戴，强化不会随装备转移。其他职业保管中的装备不会被当前职业自动替换或分解。分解根据装备品质、等级及部位返回矿石和纤维；稀有及以上装备额外返还风味精华，首领装备额外返还对应专属素材。自动分解默认关闭，可设置品质上限、装备等级上限和适用部位，所有条件同时满足才会分解。更高评分装备始终优先穿戴，已锁定装备始终保留；首领与图纸制作装备默认排除，可在设置中主动纳入。规则保存后只处理新获得或换装后入库的装备；现有仓库通过「分解匹配项」单独批量处理。

魔物随机掉落餐具矿石、玉米纤维和普通制作图纸。首领必定掉落其专属装备、素材和图纸；已经学会的重复图纸转为矿石。装备工坊中可以消耗金币、调料及素材反复制作图纸对应的装备或饰品。成品等级随角色成长，最高 Lv.40，制作出的更高评分装备也会自动穿戴。首领战失败或主动撤退后，可从保留的入口再次手动挑战。

普通怪装备基础掉率为 **12%**，制作素材基础掉率为 **30%**，幸运在此基础上继续提高掉率和品质。首领专属战利品仍为保底掉落。

每次战斗或事件结束后经过 35–65 个探索节拍，即 1× 时约 **33.25–61.75 秒**（2× 时减半）。界面不显示普通探索或短事件的剩余时间。探索结束时有 20% 概率遇见非战斗事件：林间拾荒可能获得素材，也可能空手而归；小径险情可能造成伤害，也可能成功避开；林间歇脚恢复生命；收到传单后可用金币订购素材、装备和饰品。普通事件停留约 4.75 秒（1×），之后重新进入完整探索间隔，不会立即遇怪。非战斗事件不增加击杀数、Boss 发现进度或角色经验。

传单上的商品每隔现实时间 **30 分钟** 自动轮换并补货，每款每期限购 1 份，显示刷新倒计时；装备等级在收到或刷新传单时确定，最高 Lv.40。基础素材包配送 **2 分钟**，精华和武器／防具 **5 分钟**，饰品 **10 分钟**。订购时一次性扣金币，到期自动发货，无需领取。已付款订单保留原商品、属性、价格和送达时间，不受刷新、丢弃传单、暂停、倍速、死亡或换区影响；关闭游戏后在下次打开补结算，配送和传单刷新不受 8 小时离线战斗上限限制。装备送达后优先自动穿戴，并锁定保护，可在仓库解锁后分解。最多 20 笔订单同时配送，保留最近 20 笔送达记录。查看传单与等待配送不会阻塞挂机。旧商人邀约自动转为传单。

另有三类自动处理的现实事务：**采集晶矿 3 分钟**（矿石和纤维）、**修复林间营地 5 分钟**（金币与基础素材）、**照料迷途精灵 10 分钟**（风味精华与纤维）。处理期间停止遇怪与探索，不能通过旅行或进入 Boss 房跳过；到期自动发奖，再经过完整探索间隔。事务奖励按发现时的区域确定，转职不会改奖或重置期限。暂停、倍速、刷新和关闭页面均不改变处理期限；超过 8 小时离线战斗上限仍会结算事务，并且每次只发奖一次。现实事务与契约兽复活、配送一样显示剩余现实时间。

受伤事件可以导致死亡，沿用现实时间 10 分钟复活规则。事件结果在发生时只结算一次，刷新、导入与离线追赶不会重复发奖或扣血。

天赋树分为锋芒、守护、奇遇三条分支，共 8 项天赋，覆盖全部角色属性。每个职业初始赠送 1 点，该职业每升一级获得 1 点；每项天赋最多 5 级，前置达到 3 级解锁下一层。旧存档的等级与天赋保留在当前职业，其他职业拥有各自的初始天赋点。

角色拥有攻击、生命、防御、暴击、速度、幸运、闪避、生命偷取八项属性。100 速度时角色约每 1.9 秒攻击一次，速度提高只加快角色出手；战斗倍速会同时加快双方。幸运提高装备、素材和图纸掉率，并提高装备品质。闪避成功完全免疫该次攻击，生命偷取按实际造成的伤害回血，溢出伤害不计入。速度、暴击、闪避和偷取分别上限为 400、80%、60%、50%。

角色死亡时，损失当前金币、各类制作素材与调料的 10%（逐项向上取整），保留等级、经验、装备、仓库、强化、图纸、天赋和风味。现实时间 10 分钟后满血复活；暂停、倍速、关闭页面和刷新均不会改变复活期限。死亡期间可管理养成，但无法通过换职业、强化或研发提前复活；原本暂停的冒险在复活后仍保持暂停。

调料还能用于研发 6 种风味，每种最高 5 级，所有研发效果永久叠加。共有 5 种职业：黄油骑士与驯兽师在 Lv.1 解锁，海盐游侠、焦糖法师、香草牧师分别在 Lv.4、8、12 解锁。冒险手记里有可领取金币的成就。

驯兽师空手作战，首次转职获得黄油小菇，由契约兽代替角色攻击。其他职业的武器留在各自的装备栏，新获得的武器按共享仓库规则处理，武器属性与武器栏位强化均不生效；转回其他职业会恢复该职业原先的装备。防具、饰品、天赋和风味仍然有效，契约兽只继承驯兽师自身等级、天赋与非武器属性，切换其他职业不会改变它们的数值；基础攻击、生命与防御较上一版下调约三成（初始黄油小菇为攻击 11、生命 95、防御 4）；坚韧种类偏重生命和防御，其他种类偏重攻击。

驯兽师击败普通魔物后，基础 **20%** 概率签订契约，幸运每点增加 0.1 个百分点，上限 50%。重复契约获得 **1 枚同种晶体**；重复击败已契约的首领获得 **5 枚对应晶体**。契约兽营地可指定优先伙伴，并消耗同种晶体强化：首级消耗 2 枚，此后每级多 2 枚，最高 +20，每级增加基础攻击、生命上限和防御的 12%。首次转职伙伴只赠送一次，转职不会刷新伙伴血量或休养时间。

敌人优先攻击场上的契约兽，致命伤害不会溢出到驯兽师。伙伴倒下后进入 **现实时间 1 小时** 的休养期，系统自动选择下一只可用伙伴，优先跳过死亡和未长大的宝宝。召唤耗时 **2.85 秒（1×）**，此时敌人攻击驯兽师；全部伙伴不可用时，驯兽师不进行普通攻击，等待伙伴恢复。召唤受战斗倍速与暂停影响，休养期限不受暂停、倍速、刷新、转职、死亡、关闭页面或 8 小时离线战斗上限影响，到期恢复满血。获胜后出战伙伴恢复 9% 最大生命。

驯兽师击败六个区域的 Boss 后，必定获得对应的 **Boss 宝宝**。宝宝需消耗风味精华和该首领的专属素材喂养，成长至 **3 阶** 后才可出战，最高 **5 阶**，每阶增加基础属性的 15%；继续培养至 4、5 阶时还需要下一个区域的首领素材（香草宝宝需要黄油菌核）。风味精华可从稀有装备分解或传单补给获得。晶体强化和喂养都不会提前复活休养中的伙伴。契约、晶体、成长、当前血量、优先伙伴和休养期限均随存档保存，角色死亡不会扣除契约或晶体。

- 空格：暂停 / 继续（按钮、输入框与弹窗聚焦时不拦截）。
- 右侧速度按钮：1× / 2×。
- 小窗冒险：支持 Document Picture-in-Picture 的浏览器优先使用置顶画中画；其他浏览器使用普通独立小窗，可能需要允许弹出窗口。
- 设置：开关音效、保存、导出或导入 JSON 存档。导入前会显示等级和区域，确认后替换当前进度。

## 后台运行与存档

Web Worker 发送后台时钟信号，战斗以真实时间计算，渲染与模拟分离。浏览器暂停标签页、系统休眠或关闭页面后，再次打开会补算最长 8 小时的离线战斗。暂停冒险不产生离线收益。浏览器本身不允许网页在彻底关闭后继续执行 JavaScript，因此关闭后的进度是在下次打开时结算。

每 5 秒以及切换后台、离开页面时保存到本机浏览器 localStorage。不同浏览器、不同来源（例如 localhost 和直接打开文件）的存档隔离，可使用导出/导入迁移。请勿清除浏览器存储而未备份。支持 Web Locks 的浏览器会让同一来源下的多个标签页共享一个进度所有者，其他标签页只同步显示，避免重复收益。

存档格式已升级至 v6，继续使用原来的存储键，兼容 v1/v2/v3/v4/v5 的等级、金币、调料、职业、强化、风味、装备和地图解锁进度。死亡期限、隐藏区域进度、装备仓库、图纸、天赋、自动分解规则、装备锁定、旅途事件、传单刷新期限、配送订单、契约兽养成、各职业独立进度与现实事务一并保存。旧存档的等级、经验、装备、强化与天赋全部归当前职业保留，其他职业从 Lv.1 开始；原有契约、晶体、宝宝成长和复活期限均保留，契约兽当前生命按新的生命上限收敛。旧版 v1/v2 存档迁移后自动分解默认关闭。

## 项目结构

- `src/engine.js`：独立、可测试的回合战斗与经济系统，使用可复现的随机序列。
- `src/progression.js`：装备品质与属性、制作图纸、首领素材及天赋树定义。
- `src/art.js`：原创代码绘制的像素角色、魔物、调料和多层场景。
- `src/app.js`：界面、存档、后台时钟、音效与小窗。
- `style.css`：桌面与手机适配。
- `scripts/`：无第三方依赖的开发服务器和单文件打包工具。

角色美术根据提供的低分辨率像素职业参考重新绘制，使用爆米花、餐具和调料主题。没有外部字体、图片或网络运行依赖。
